# homebrew-astgen

> **Deprecated:** this tap no longer receives updates. Since v2026.9.0, astgen
> releases with release-kit v2, which publishes the Homebrew formula in the
> [grahambrooks/astgen](https://github.com/grahambrooks/astgen) repository itself.
> Switch to that tap:

```sh
brew untap grahambrooks/astgen   # if you previously tapped this repository
brew tap grahambrooks/astgen https://github.com/grahambrooks/astgen
brew install grahambrooks/astgen/astgen
```
